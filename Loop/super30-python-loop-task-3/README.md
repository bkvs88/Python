# super30-python-loop-task-3
Real-World Loop Challenges

## Real-World Loop Challenges

This repository contains Python Jupyter notebooks that practice common loop-based problems and basic control flow. Each notebook addresses a specific programming challenge using loops and fundamental control structures.

---

## 📚 Notebooks and Questions Map

| # | Question | Notebook | Description |
|---|----------|----------|-------------|
| 1 | Calculate total transaction value without using `sum()` and find highest & lowest without `max()`/`min()` | [`transactions_sum.ipynb`](./transactions_sum.ipynb) | Sum list values and track min/max values in one pass |
| 2 | Find the average temperature from a list | [`average_temperature.ipynb`](./average_temperature.ipynb) | Compute average using loop-based accumulation |
| 3 | Count how many students scored: 90+, 75–89, 50–74, below 50 | [`students_grades.ipynb`](./students_grades.ipynb) | Categorize marks into ranges using conditionals in a loop |
| 4 | Create a simple login system with a maximum of 3 password attempts | [`password_attempts.ipynb`](./password_attempts.ipynb) | Demonstrates `for` loop with early exit and `else` for lockout |
| 5 | Print only products costing more than ₹2,000 | [`products_gt_2k.ipynb`](./products_gt_2k.ipynb) | Iterate dictionary and filter by value |
| 6 | Accept 10 numbers from the user and store them in a list using a loop | [`store_in_list.ipynb`](./store_in_list.ipynb) | Collect input and append to list in a loop |
| 7 | Count the frequency of every character in a string without using `Counter` | [`character_counter.ipynb`](./character_counter.ipynb) | Build a dictionary of character counts via looping |
| 8 | Find the second-largest number in a list without using `sort()` | [`second_largest.ipynb`](./second_largest.ipynb) | Track top two values in a single pass through the list |
| 9 | Check whether a string is a palindrome using loops | [`palindrome_check.ipynb`](./palindrome_check.ipynb) | Compare characters from both ends using indexing in a loop |
| 10 | Create a number pattern (1, 12, 123, 1234, 12345) | [`number_pattern.ipynb`](./number_pattern.ipynb) | Build and print incremental concatenation using a loop |
| 11 | Basic ATM simulation: Check balance, Deposit, Withdraw, Exit | [`atm_simulation.ipynb`](./atm_simulation.ipynb) | Simple interactive loop-based menu for ATM operations |

---

## 🎯 Key Concepts Covered

- Loop basics (`for`, `while`) and iteration patterns
- Aggregation patterns (summing, averaging)
- Conditional logic inside loops for filtering and categorization
- Tracking state across iterations (min/max, top-two values, counters)
- Building simple interactive programs using input and loop-based menus
- Working with lists and dictionaries without relying on convenience functions (`sum()`, `min()`, `max()`, `Counter`)

## 📖 How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/bkvs88/super30-python-loop-task-3.git
   ```

2. Navigate to the repository:
   ```bash
   cd super30-python-loop-task-3
   ```

3. Open Jupyter Notebook / JupyterLab and run any `.ipynb` file to view and execute the code examples:
   ```bash
   jupyter notebook
   ```

4. Interact with notebooks that require user input (password prompts, ATM, number input) via the notebook input cells.
